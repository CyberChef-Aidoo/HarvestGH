Create a Supabase Account
Sign up for free at supabase.com
In Progress

Where to go

supabase.com → Start your project → Sign up with GitHub or Email
1
Open your browser and go to supabase.com
2
Click the big green "Start your project" button
3
Click "Sign up" — you can use your GitHub account (fastest) or create an account with your email
4
If you used email, check your inbox for a verification email and click the link to confirm your account
5
Once logged in, you will see the Supabase dashboard with a button that says "New project"
Supabase is completely free for small projects. You get 500MB database, 1GB storage, and 50,000 monthly active users on the free plan — more than enough to run HarvestGH.
✅ Once you are logged in to Supabase, mark this done

Create a New Supabase Project
This is your HarvestGH database
To Do

Dashboard Path

Dashboard → New project → Fill in details → Create project
1
On the Supabase dashboard, click "New project"
2
Organisation: select the default (your username) or create one called HarvestGH
3
Project name: type harvestgh
4
Database password: click "Generate a password" and copy it somewhere safe — you will need it if you ever connect a database tool directly. It will not be needed for HarvestGH normally.
5
Region: select EU West 1 (Ireland) — this is the closest available to Ghana and gives you the best speed
6
Click "Create new project" — wait about 2 minutes. You will see a loading spinner. Do not close the tab.
7
When it finishes, you will see your project dashboard with sections like Table Editor, SQL Editor, Authentication, Storage, and Settings
Your project URL will look like https://abcdefghij.supabase.co — you will copy this in the next step.
✅ Once your project dashboard loads, mark this done
3
Get Your API Keys
You need 2 values: your Project URL and your anon key
To Do

Where to find your keys

Left sidebar → Settings → API → Copy Project URL + anon key
1
In your Supabase project, click Settings (the gear icon ⚙️) at the very bottom of the left sidebar
2
Click "API" in the settings menu
3
You will see "Project URL" — it looks like https://abcdefghij.supabase.co — click the copy icon next to it and paste it below
4
Below that, under "Project API keys", you will see the anon public key — a very long string starting with eyJ... — copy it and paste it below
5
Do NOT copy the "service_role" key — only copy the anon public key. The service key gives full access to your database and should never be in a browser.
Starts with https:// and ends with .supabase.co
A very long string starting with eyJ — this is safe to put in browser files
Save these somewhere safe — you will also need them when you deploy to Netlify.
✅ Once connection test shows green, mark done
4
Enable Email Authentication
This lets you log into the admin panel with email + password
To Do

Where to enable Email Auth

Left sidebar → Authentication → Providers → Email → Enable toggle → Save
1
In the left sidebar, click "Authentication" (the lock icon 🔒)
2
Click "Providers" in the Authentication submenu
3
You will see a list of providers. Find "Email" and click on it
4
Toggle "Enable Email provider" to ON (it turns green)
5
Turn OFF "Confirm email" — this means users do not need to verify their email when you create their account
6
Click "Save"
✅ Once Email provider is enabled and saved, mark done
5
Run the Database SQL
Creates all 9 tables HarvestGH needs
To Do

Where to run the SQL

SQL Editor → New query → Paste SQL below → Run
1
In the left sidebar, click "SQL Editor" (the code icon </>)
2
Click "New query" at the top left
3
Copy the entire SQL below using the copy button
4
Paste it into the SQL editor (click in the empty text area and press Ctrl+V)
5
Click the green "Run" button (or press Ctrl+Enter)
6
You should see "Success. No rows returned" at the bottom — this means all 9 tables were created successfully
-- Loading SQL from setup.sql...
If you see an error: The most common cause is running the SQL twice. If you see "relation already exists", that is fine — your tables are already created. Click the green "Run" button again — it should succeed.
✅ Once you see "Success" in Supabase, mark done

Create Storage Buckets
For product photos and crop images
To Do

Where to create buckets

Storage → New bucket → Name it → Check Public → Create
1
In the left sidebar, click "Storage" (the storage icon)
2
Click "New bucket"
3
Name: product-images — check "Public bucket" — click Create bucket
4
Click "New bucket" again
5
Name: crop-images — check "Public bucket" — click Create bucket
6
You should now see two buckets listed: product-images and crop-images
Making the buckets public means photos you upload for products will be visible to anyone who visits your marketplace — which is exactly what you want.
✅ Once both buckets are created, mark done
7
Create Your Admin Login
The email and password you use to log into admin.html
To Do

Where to create your admin user

Authentication → Users → Add user → Create new user
1
In the left sidebar, click "Authentication"
2
Click "Users" (the second tab at the top)
3
Click "Add user" (top right) → "Create new user"
4
Email: enter any email you want. Example: ibrahim@harvestgh.com or your personal email. You will type this when logging into admin.html
5
Password: choose a strong password. Must be at least 6 characters. Example: HarvestGH2026!. Write it down somewhere safe.
6
Click "Create user". You will see the user appear in the list.
⚠️ This is stored only in your browser — not sent anywhere.
This is the ONLY way to log into admin.html. HarvestGH does not assign you a default password. You just created your own email and password above in Supabase.
✅ Once you see your user in the list, mark done

Add Your Credentials to HTML Files
Replace the placeholder text with your real Supabase URL and key
To Do

The fastest method — VS Code Find & Replace

VS Code → Ctrl + Shift + H → Replace All
1
Open the harvestgh folder in VS Code (download from code.visualstudio.com if you don't have it)
2
Press Ctrl + Shift + H to open Find & Replace across all files
3
In the Search box, type: YOUR_SUPABASE_URL_HERE
4
In the Replace box, paste your Supabase Project URL (e.g. https://abcdefghij.supabase.co)
5
Click "Replace All" — you should see it replaced in about 18 files
6
Now in the Search box, type: YOUR_SUPABASE_ANON_KEY_HERE
7
In the Replace box, paste your anon public key
8
Click "Replace All"
9
Press Ctrl + S to save all changes

Test Everything & Go Live
Log into admin, add your first product, deploy to Netlify
To Do
1
Test admin login: Open admin.html in your browser. Enter the email and password you created in Step 7. Click Sign In — you should see your dashboard.
2
Add your first product: In admin, click Products → Add Product. Fill in the details (crop name, price, quantity, region, photo). Click Save. Then open listings.html — your product should appear.
3
Update site settings: In admin, go to Site Settings and update your phone number, WhatsApp, and tagline.
4
Add your logo and photo: Put logo.png (your logo) and ibrahim.jpg (your photo) in the harvestgh folder alongside the HTML files.
5
Deploy to Netlify: Go to netlify.com, create a free account, and drag your entire harvestgh folder into the dashboard. Your site will be live in under 1 minute.
6
Set your site name: In Netlify → Site settings → Domain management → Change site name to harvestgh → your site will be at harvestgh.netlify.app
🎉 Mark done when your admin panel is working!
